PASO 2 — Custom SMTP (Authentication → SMTP Settings)

  Opcion A — Resend (recomendado, rapido)
  ----------------------------------------
  1. Crear cuenta en https://resend.com
  2. Verificar dominio monitoring.cl (o usar onboarding@resend.dev solo pruebas)
  3. API Keys → crear key
  4. En Supabase SMTP:

     Sender email:     noreply@monitoring.cl   (o el dominio verificado)
     Sender name:      Portal del Trabajador Monitoring
     Host:             smtp.resend.com
     Port:             465
     Username:         resend
     Password:         <API KEY de Resend>

  Opcion B — Microsoft 365
  ------------------------
     Host:             smtp.office365.com
     Port:             587
     Username:         cuenta que envia (ej. noreply@monitoring.cl)
     Password:         contraseña de aplicacion / SMTP
     Sender email:     misma cuenta autorizada

  ERRORES COMUNES:
  - Host con espacios al final → falla DNS
  - Host con https:// → quitar protocolo
  - Admin email y Username intercambiados
  - Puerto 25 bloqueado → usar 587 o 465
